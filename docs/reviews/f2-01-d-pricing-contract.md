## 4. Aritmetika durasi eksak (PROPOSED, batas terverifikasi probe)

- Larangan: time.Duration/time.Time.Sub (jenuh ~292 tahun — probe: Sub atas rentang penuh = 2562047h47m16.854775807s == MaxInt64 ns) dan float Hours/Ceil (tak eksak). Rumus: diff_us = ends.UnixMicro() - starts.UnixMicro() atas instants UTC ternormalisasi (mikrodetik); units = diff_us / 86400000000 + (1 bila diff_us % 86400000000 != 0); total = checked rate x units (overflow -> 422, bagian 8).
- Batas terverifikasi probe Go 1.27.3 (program scratch /tmp/umnia-price-probe, benar-benar dijalankan 2026-11-07): UnixMicro tahun 1 = -62135596800000000; UnixMicro 9999-12-31T23:59:59.999999Z = 253402300799999999; selisih maksimum 315537897599999999 < MaxInt64 9223372036854775807, jadi pengurangan tak dapat overflow pada rentang yang didukung; units maksimum 3652059. Implementasi tetap memeriksa ends_us > starts_us (invarian draft) dan gagal 500 bila dilanggar.
- Kasus: 24 jam -> 1 unit; 24 jam + 1 mikrodetik -> 2 unit; 49 jam -> 3 unit; >292 tahun (0001-01-01 -> 0294-01-01): Sub jenuh tetapi diff UnixMicro eksak 9246182400000000 -> 107016 unit; rentang maksimum (0001-01-01T00:00:00Z s.d. 9999-12-31T23:59:59.999999Z) -> 3652059 unit. Rate maksimum yang muat pada units maksimum: 2525526569218; rate 2525526569219 x 3652059 melampaui int64 -> 422. Tidak pernah wrap/clamp/truncate/underquote diam-diam.
- Contoh numerik (sintetis, bukan tarif nyata): versi harga amount_minor "150000", currency "IDR" (string contoh saja), valid 2026-12-01 s.d. 2027-01-01. Draft 2026-12-10T09:00:00Z s.d. 2026-12-13T09:00:00Z = 72 jam = 3 unit x 150000 = total_minor "450000". Periode 49 jam -> ceil 3 unit -> "450000". Tanpa pajak/biaya/deposit dalam total ini.

## 5. Mata uang dan representasi JSON (PROPOSED)

- amount_minor/total_minor di API adalah STRING desimal kanonis (bukan JSON number): JSON number int64 saja tidak menjamin konsumen JavaScript/Nuxt mempertahankan integer di luar 2^53-1. Disimpan BIGINT, diurai/diperiksa eksak di Go (strconv.ParseInt sesudah validasi bentuk). Units tetap JSON number (maksimum 3652059 < 2^53, aman).
- Bentuk kanonis: "0" diizinkan; nonnegatif; maksimum "9223372036854775807"; tanpa leading zero kecuali "0" sendiri ("0150000" ditolak); tanpa tanda "+" / "-" ("-1", "+150000" ditolak); tanpa fraksi/eksponen ("150000.0", "1.5e5" ditolak); null/bukan-string ditolak; semua -> 400. Tidak ada dependensi/framework desimal baru.
- Currency = kode 3 huruf ASCII [A-Z]{3} yang wajib diisi pemanggil; tanpa default server (DEFAULT 'IDR' pada sketsa TIDAK diadopsi); string 3 huruf besar BUKAN klaim mata uang ISO tervalidasi atau kebijakan komersial yang disetujui — hanya sintaks yang disimpan. Tanpa konversi mata uang, kurs, atau klaim kepatuhan pajak/hukum. Pajak/biaya/deposit terpisah; quote tidak mengembalikan field untuk ketiganya. API tidak pernah membagi 100 atau memformat desimal.

## 8. Konkurensi, locking, dan error aritmetika (PROPOSED)

- Create versi harga mengambil workspace-row lock B3 yang sama (setelah otorisasi, sebelum semua bacaan), lalu cutoff, replay, referensi, no-backdate, overlap, INSERT, audit, commit — satu transaksi READ COMMITTED. Dua create yang overlap -> satu 201 + satu 409 (EXCLUDE backstop).
- Total di luar batas yang dapat diwakili (rate x units melampaui int64) -> 422 "total di luar batas yang dapat diwakili": permintaan valid yang tidak dapat dikutip dalam batas moneter yang didukung, BUKAN outage backend. Gagal DB/izin yang tak terduga tetap 500.
- Quote adalah bacaan tanpa lock (snapshot READ COMMITTED): versi yang dibuat sesudah quote dibaca tidak mengubah quote yang sudah dikembalikan, karena quote tidak disimpan. Timestamp mulai-transaksi (now()) BUKAN urutan commit: quote membawa price_version_id + rentang valid sehingga dasarnya eksplisit, bukan disimpulkan dari created_at. Clock_timestamp() yang dipakai sebagai cutoff ditangkap SESUDAH lock (bagian 7), bukan sebelum lock yang memblokir.
- Bacaan availability yang sukses lebih dulu BUKAN bukti reservasi dan BUKAN harga yang terkunci — harga mengikat hanya ada sesudah gate perjanjian (bagian 2). Hold expiry/release dan deactivate/revoke tidak menyentuh price_versions; perjanjian masa depan me-resolve ulang di bawah lock pada saat commit.
